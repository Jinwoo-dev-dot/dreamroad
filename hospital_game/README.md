# DREAM ROAD: 종합병원 간호일지

순수 HTML5 Canvas + JavaScript로 만든 간호사 시뮬레이션 게임입니다.
빌드 과정 없이 `index.html`을 브라우저로 열면 바로 실행됩니다 (권장: 로컬 서버로 열기).

```bash
cd hospital_game
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080 접속
```

## 조작법

모든 진행은 **마우스 클릭**으로 이루어집니다. 붕대/깁스는 환부 위에서 **마우스를 드래그**해서
직접 감아야 하고, 수액은 혈관 위치를 클릭 → 바늘 삽입 지점을 클릭해서 직접 처치합니다.

## 하루의 흐름

1. **옷장 (출근 준비)**: 상의·하의·스타킹·신발·헤어·액세서리를 카테고리별로 골라 오늘의
   유니폼을 완성하고 "출근하기"를 누릅니다.
2. **출근길**: 버스를 타고 병원으로 향하는 짧은 연출이 자동으로 진행됩니다.
3. **물품창고**: 붕대·주사기·깁스·약품·수액 5종 상자를 각각 10개씩 클릭해서 채워넣어야
   병동으로 이동할 수 있습니다.
4. **접수/분류**: 환자가 증상을 말하면(예: "발목을 삐끗했는데 걷기가 힘들어요"),
   정형외과·내과·안과·치과 중 알맞은 곳으로 안내합니다. 틀리면 환자가 다시 알려주고
   재시도할 수 있습니다.
5. **처치**: 화면 오른쪽 위 처방전에 진단명과 처방이 표시됩니다.
   - **붕대**: 환부 위를 마우스로 드래그해서 감아 게이지를 채운 뒤 "고정하기".
   - **깁스**: 패딩 감기 → 깁스 붕대 감기 → 굳히기(대기) 3단계로 진행됩니다.
   - **수액/주사**: 혈관 위치 클릭 → 표시된 지점에 바늘 꽂기 → 테이프로 고정 →
     (수액인 경우) 수액백을 걸고 드립이 끝날 때까지 기다립니다.
   - **약 처방**: 선반에 놓인 몇 개의 약 중 처방전과 일치하는 것을 골라 환자에게 전달합니다.
6. 환자 10명을 모두 진료하면 자동으로 **퇴근** 화면으로 넘어가 오늘의 진료 수와 분류
   정확도를 보여주고, "다음 날 준비하기"를 누르면 다시 옷장부터 하루가 시작됩니다.

## 진료과 & 질병 데이터

정형외과·내과·안과·치과 4개 과에 각각 10개씩, 총 40개의 질병이 정의되어 있고
(`js/data.js`), 매일 그중 10개를 무작위로 뽑아 환자로 등장시킵니다. 각 질병은 환자가
말하는 증상 대사, 진단명, 그리고 붕대/깁스/수액/약 중 알맞은 처방을 담고 있습니다.

## 파일 구조

- `index.html`, `style.css` — 진입점 및 UI 스타일
- `js/util.js` — 전역 상태와 유틸리티
- `js/data.js` — 4개 진료과 x 10개 질병 데이터
- `js/wardrobe.js` — 출근 준비(옷 고르기) 씬, 간호사 캐릭터 렌더링
- `js/commute.js` — 출근길 전환 연출
- `js/supply.js` — 물품창고 보충 미니게임
- `js/station.js` — 접수/분류(환자 안내) 씬
- `js/treatments.js` — 붕대/깁스/수액·주사/약 처방 미니게임
- `js/ui.js` — HUD, 자막, 퇴근 요약 화면
- `js/main.js` — 부트스트랩, 입력 처리, 메인 루프
