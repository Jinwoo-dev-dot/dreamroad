# DREAM ROAD: 크라임 시티

순수 HTML5 Canvas + JavaScript로 만든 탑다운 크라임 시뮬레이션 게임입니다.
빌드 과정 없이 `index.html`을 브라우저로 열면 바로 실행됩니다 (권장: 로컬 서버로 열기).

```bash
cd crime_game
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080 접속
```

## 조작법

- **마우스 이동**: 캐릭터가 커서를 따라 걷거나(가까울 때) 뜁니다(멀리 있을 때).
- **마우스 클릭**: 장착한 무기로 공격 (칼: 근접 베기 / 총: 발사).
- **숫자 1 / 2 / 3**: 맨손 / 칼 / 총 무기 교체 (소지 중인 무기만 선택 가능).
- **E**: 문 열기, 물건 훔치기, 무기 줍기 등 상호작용.

## 게임 흐름

1. **집 (홈)**: 시작하면 방 안. 테이블 위의 칼과 총(총알 6발 장전)을 `E`로 챙기고 문으로 나갑니다.
2. **도시**: 7×7 블록 규모의 넓은 오픈월드 도시. 주민 NPC가 인도를 배회하고, 공원에는 현금으로
   총알을 파는 밀거래상이 있습니다.
   - 칼/총으로 NPC나 **경찰관**을 공격하면 사망 애니메이션(래그돌+혈흔)과 함께 수배도가 오릅니다.
     경찰관을 죽이면 즉시 최고 수배 단계가 되고 잡힐 경우 무조건 사형이 확정됩니다.
   - 편의점(🏪)에 들어가 진열대에서 `E`로 물건을 훔칠 수 있습니다. 점원에게 들키면 신고당합니다.
   - 총은 탄약이 소진되면 발사되지 않습니다 — 공원 밀거래상에게 현금 50당 총알 6발을 살 수 있습니다.
3. **수배 & 추격**: 수배도가 오르면 경찰이 근처에 출동해 사이렌을 울리며 플레이어를 추격합니다.
4. **체포**: 경찰에게 붙잡히면 정지 → 무릎 꿇기 → 수갑 채우기 → 순찰차 호송 → 경찰서 이송까지
   자동 컷씬으로 진행됩니다.
5. **재판**: 법정에서 검사의 공소사실 → 변호인 변론 → 판사 숙고 → 판결 순으로 진행되며,
   살해·절도·경찰관 살해·탈옥 전력에 따라 형량이 정해집니다. 일반인 4명 이상 살해, 경찰관 살해,
   또는 탈옥 전력이 있으면 **사형**이 선고됩니다.
6. **교도소**: 감방동/복도/식당/작업장/운동장으로 구성된 공간에서 기상-식사-작업-운동-소등으로
   이어지는 하루 일과가 시계와 함께 자동으로 진행됩니다. 소등 시간에는 감방에 갇혀 이동이 제한됩니다.
   - **탈옥**: 운동 시간에 운동장 구석의 "약해진 철조망" 근처에서 `E`를 3초간 누르고 있으면 탈옥을
     시도합니다. 경비가 가까이 있으면 발각되어 형기가 3일 추가되고, 성공하면 도시로 탈출하지만
     즉시 전국 최고 수배 단계가 됩니다 (무기는 압수된 채).
   - **사형수**: 사형이 선고되면 사형수 독방에서 3일을 보낸 뒤, 호송 → 결박 → 최후 진술 → 카운트다운
     → 집행으로 이어지는 사형 집행 시퀀스가 진행됩니다.
   - 형기를 무사히 마치면 출소해 다시 집으로 돌아가고(무기·소지품은 압수), 새로운 판을 이어갈 수
     있습니다.

## 파일 구조

- `index.html`, `style.css` — 진입점 및 UI 스타일
- `js/util.js` — 전역 상태와 수학 유틸리티
- `js/audio.js` — 웹오디오 기반 절차적 효과음 (총성, 사이렌, 수갑, 판사봉 등)
- `js/world.js` — 도시 맵 생성/렌더링/충돌
- `js/entities.js` — 플레이어/NPC/경찰/총알/파티클 및 전투 로직
- `js/interiors.js` — 집/편의점 실내 씬, 밀거래상 상호작용
- `js/arrest.js` — 수배 시스템과 체포(수갑)·호송 시퀀스
- `js/trial.js` — 재판 시퀀스와 형량 결정 로직
- `js/jail.js` — 교도소 공간, 하루 일과 스케줄, 탈옥 시스템
- `js/execution.js` — 사형 집행 시퀀스
- `js/ui.js` — HUD(수배 별, 범죄 기록, 무기바, 자막, 미니맵, 교도소 시계)
- `js/main.js` — 부트스트랩, 입력 처리, 카메라, 메인 루프
