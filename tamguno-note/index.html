저장소 연결하기

다운로드해서 쓰는 버전이라 기기·창 사이에 내용을 동기화하려면
무료 Firebase 프로젝트를 하나 연결해야 해요. (한 번만 하면 돼요)

  1. Firebase 콘솔에서 새 프로젝트 만들기
  2. 왼쪽 메뉴 빌드 → Realtime Database → 데이터베이스 만들기 → 테스트 모드로 시작
  3. 왼쪽 메뉴 빌드 → Authentication → Sign-in method → 이메일/비밀번호 사용 설정 (회원가입·로그인에 필요해요)
  4. ⚙️ 프로젝트 설정 → 내 앱 → 웹 앱 추가(</>) → 나오는 코드 전체 복사 (import 문 포함해도 괜찮아요)
  5. 아래 칸에 복사한 걸 그대로 붙여넣고 저장하기

이 설정은 지금 쓰는 브라우저에만 저장돼요. 다른 기기에서도 동기화하려면 그 기기에서도 같은 정보를 한 번 붙여넣어 주세요.
