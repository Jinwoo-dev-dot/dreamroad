# 탐구노트

조사·수행평가 기록용 리서치 노트 웹앱. `index.html` 파일 하나로 동작하는 정적 페이지라 빌드 없이 브라우저에서 바로 열면 됩니다.

## 주요 기능

- 노션 스타일 아웃라인 편집기 (제목/인용/코드/할일/표/이미지 등)
- Firebase Authentication(이메일/비밀번호) 회원가입·로그인, 기기 간 동기화
- 로그인 후 노트를 **섹션**(기본값: 연구 / 수행평가)으로 분류·정리, 섹션은 자유롭게 추가·이름변경·삭제 가능
- 이메일로 다른 가입자에게 노트를 공유해 함께 편집
- 맞춤법 검사: 본문을 클립보드에 복사한 뒤 [나라스펠러](https://nara-speller.co.kr/speller/)를 새 창으로 열어줍니다. 나라스펠러는 공개 API가 없는 상용 서비스라 자동 연동은 불가능해서, 새 창에 Ctrl+V로 붙여넣어 검사하는 방식입니다.

## 저장소(Firebase) 연결

기본으로 프로젝트에 내장된 Firebase 설정을 사용합니다. 다른 Firebase 프로젝트를 쓰려면 로그인 화면의 "저장소 설정 변경"에서 프로젝트 설정을 붙여넣으세요. 이때 Firebase 콘솔에서 **Realtime Database**와 **Authentication → 이메일/비밀번호 로그인**을 모두 켜둬야 합니다.
