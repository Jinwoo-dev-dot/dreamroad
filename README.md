# dreamroad

이 저장소에는 캠스터디 앱의 서로 다른 두 구현과 별개의 웹 프로젝트가 있습니다.

- **`camstudy_app/`** — Flutter, 크로스플랫폼 (Windows 데스크톱 + iOS + Android). 현재 진행 중인 버전. 자세한 내용은 [`camstudy_app/README.md`](camstudy_app/README.md) 참고.
- **`CamStudy/`** — SwiftUI, iOS 전용 (Xcode 필요). 초기 프로토타입. 자세한 내용은 [`CamStudy/README.md`](CamStudy/README.md) 참고.
- **`tamguno-note/`** — 탐구노트, 조사·수행평가 기록용 정적 웹 노트 앱. 자세한 내용은 [`tamguno-note/README.md`](tamguno-note/README.md) 참고.
